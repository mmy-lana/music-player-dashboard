# 🎵 Music Player Dashboard (Spotify Clone)

A modern, responsive Music Player Web Dashboard built with **Vue 3**, **Tailwind CSS**, and **Pinia**. Features an interactive mock audio stream controller, Spotify dark theme aesthetic, and reactive state management.

🚀 **Live Demo:** [https://music-player-dashboard.vercel.app](https://music-player-dashboard.vercel.app)

---

## ✨ Features

- 🎧 **Audio Stream Controls:** Full playback engine supporting Play, Pause, Scrubbing/Seeking, Volume control, Mute, Shuffle, and Repeat modes.
- 🎨 **Spotify Dark Theme UI:** Pixel-perfect dark player design using Tailwind CSS with custom scrollbars and responsive layout.
- ⚡ **Reactive State Management:** Global state handling for tracks, queue, and playback via Pinia.
- 📋 **Interactive Playlist:** Dynamic track list displaying current track indicators, hover quick-play buttons, track durations, and like toggles.
- ♿ **Accessible Primitives:** Clean, SOLID-compliant atomic UI components with ARIA labels and hover micro-interactions.

---

## 🛠 Tech Stack

- **Framework:** Vue 3 (Composition API + `<script setup>`)
- **Build Tool:** Vite
- **Styling:** Tailwind CSS
- **State Management:** Pinia
- **Icons:** Lucide Vue Next
- **Type Safety:** TypeScript

---

## 🚀 Local Setup

```bash
# Clone the repository
git clone https://github.com/YOUR_USERNAME/music-player-dashboard.git
cd music-player-dashboard

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
